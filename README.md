# INSANETUBE 🚀

A high-performance Android streaming video client built with Jetpack Compose, Material Design 3, Room Database, and Kotlin Coroutines.

## 📱 APK Download & Installation

You can get the compiled APK in any of the following ways:

### 1. Direct Repository APK
The pre-compiled debug APK is included directly in this repository:
- **Path**: [`apk/insanetube-app-debug.apk`](apk/insanetube-app-debug.apk)
- Download this file to your Android phone or emulator and install it.

### 2. Automated GitHub Actions Builds
Every time changes are pushed to this GitHub repository, GitHub Actions automatically builds a fresh APK:
1. Go to the **Actions** tab on your GitHub repository.
2. Select the latest **Build & Release APK** workflow run.
3. Scroll to the **Artifacts** section at the bottom and download **`insanetube-debug-apk`**.

### 3. Build Locally using Gradle
```bash
./gradlew assembleDebug
```
The output APK will be generated at:
`app/build/outputs/apk/debug/app-debug.apk`
